# 중국어 원어 짝짓기 검수 요청 (시범 198절)

## 상태 요약 (재논의 금지)
- 프로젝트: JBCH 성경 앱, 원어 단어 ↔ 중국어(간체) 직역 짝짓기(WordAlignment)
- 고정 원칙: 중국어 직역 문장은 바꾸지 않는다. OriginalText.sqlite 단어 번호 기준. 판본 제외 단어([TR]/[Byz]/[LXX])는 짝을 짓지 않는다.
- 이번 요청: 아래 데이터 파일의 짝이 맞는지만 판정한다. 설계·규칙에 대한 의견은 쓰지 않는다.

## 데이터 형식
절마다:
```
## 책번호:장:절
ZH: 중국어 직역 문장
번호 원어 (영어 뜻) → 「짝지은 중국어 구간」 | — (짝 없음) | (제외: 직역에 없는 사본 단어)
```

## 짝짓기 규칙 (판정 기준)
1. 구간은 중국어 문장 안의 이어진 글자 묶음이며 뜻 단위(낱말)로 자른다. 문장부호는 구간 밖.
2. 원어 단어 하나는 구간 하나. 여러 원어 단어가 같은 구간을 함께 쓸 수 있다(예: 太初 = Ἐν + ἀρχῇ).
3. 중국어에 관사가 없으므로 원어 관사·히브리어 목적격 표지(אֵת)·대응 글자가 없는 접속사는 "—"가 정상이다.
4. 동사 뒤 了·着·过, 명사 뒤 们은 그 낱말에 포함한다.
5. "(제외…)" 단어는 판정하지 않는다.

## 판정할 것
- 틀린짝: 구간이 그 원어 단어의 뜻과 다르다.
- 누락: "—"인데 중국어 문장에 분명히 대응하는 말이 있다.
- 범위: 뜻은 맞지만 구간이 너무 넓거나 좁다(다른 단어의 몫까지 포함 등).

## 답변 형식 (엄격, 토큰 절약)
- **문제가 있는 단어만** 한 줄씩 탭으로 구분해 출력한다. 맞는 단어는 출력하지 않는다.
- `절<TAB>단어번호<TAB>판정(틀린짝|누락|범위)<TAB>맞는 구간(중국어 문장에 있는 글자 그대로, 없으면 —)<TAB>근거(20자 이내)`
- 마지막 줄에 `요약<TAB>검토한 절 수<TAB>문제 단어 수`
- 설명 문단, 표 장식, 인사말은 쓰지 않는다.
- 결과를 파일로 만들 수 있으면 `align_zh_review_<NN>_result.tsv`(NN은 데이터 파일 번호)로 저장한다.

예:
```
1:5:24	3	틀린짝	同	"with"는 同, 行은 1번
요약	99	1
```
