# 코드 리뷰 요청 — 원문 정보 화면 개편 (interlin1)

첨부한 `code_review_01.diff`는 SwiftUI 앱의 변경분입니다(git diff 형식, 11개 파일, 약 1,900줄). 이 diff를 **독립적으로** 리뷰해 주세요. 다른 리뷰어 한 명이 이미 1차 리뷰를 마쳤습니다. 당신은 2차이므로, 같은 결론을 반복하기보다 놓친 문제를 찾는 데 집중해 주세요.

## 실행 환경 (추측 금지)
- iOS 18 / iPadOS 18 / macOS 26
- Swift 5 언어 모드
- 빌드 설정
  - `SWIFT_DEFAULT_ACTOR_ISOLATION = MainActor`: 표시가 없는 타입과 함수는 기본으로 MainActor입니다.
  - `SWIFT_APPROACHABLE_CONCURRENCY = YES`
  - `SWIFT_UPCOMING_FEATURE_MEMBER_IMPORT_VISIBILITY = YES`
- 패키지 `BibleResearchPlatform`은 swift-tools 6.0이고, 기본 격리가 없습니다.
- SQLite C API를 직접 씁니다. 연결은 읽기 전용(`SQLITE_OPEN_READONLY`)입니다.
- 다중 창(UIApplicationSupportsMultipleScenes)을 씁니다. macOS에서 원문 정보 화면은 성경 창에 붙은 `.sheet`입니다.
- 정보가 부족해 판단할 수 없으면 추측하지 말고 "확인 필요"로 분류해 주세요.

## 변경 내용 요약
1. 직역 카드
   - 원어 단어마다 "단어별 칸"을 둡니다. 각 칸은 3줄입니다: 직역 문장 속 말 / 영어 문맥 번역 / 원어.
   - 칸을 누르면 아래 원어 카드로 스크롤하고 잠깐 강조합니다.
   - '원어 어순' 섹션을 지웠습니다.
   - 영어 직역(LSV)은 항상 펼친 상태로 보입니다.
2. 원어 카드 재구성
   - 연필(뜻 수정) 버튼을 오른쪽 위로 옮겼습니다.
   - 품사 정보를 전역 토글로 바꿨습니다. `@AppStorage`에 저장하고 기본값은 닫힘입니다.
   - "이 절에서: ○○" 줄을 넣었습니다.
   - 아래 줄은 [돋보기 N절] | 네이버 | biblehub 입니다.
3. 짝짓기 데이터 조회 (`WordAlignment` 테이블, 아직 번들에 없음 → nil이 정상)
   - `start`는 직역 문장 안의 Unicode scalar 기준 0부터 세는 오프셋입니다.
   - 표시 규칙: `start` 위치에서 phrase가 직역과 일치할 때만 보여 줍니다.
4. "이 단어가 쓰인 구절" 화면 (새 파일 `OriginalWordOccurrencesView.swift`)
   - Strong 번호로 전체 테이블을 스캔합니다(백그라운드).
   - 성경책별 필터 칩을 둡니다.
   - 본문 미리보기는 번역본 파일 전체를 한 번 읽어 만듭니다.
   - 구절을 누르면 시트가 닫히고, `onDismiss`에서 성경 화면이 그 절로 이동합니다.
   - iOS에서는 NavigationStack에 push로 엽니다. macOS에서는 시트 안에 겹쳐서 보여 줍니다.

## 중점 확인 항목
1. 동시성
   - `Task.detached`와 MainActor 사이에서 상태가 바르게 넘어가는지
   - 결과가 늦게 도착할 때 경쟁이 없는지
   - Sendable 위반이 없는지
   - SQLite 연결을 스레드끼리 공유하지 않는지
2. 런타임 크래시 가능성: 인덱스 범위, 강제 언래핑, 오프셋 계산
3. 성능
   - 결과가 7,000절 이상일 때 목록과 필터
   - body를 다시 그릴 때마다 무거운 계산을 하지 않는지
   - 메모리 사용
4. 화면 흐름
   - 시트 닫힘 → 이동과 메모 전환이 충돌하지 않는지
   - macOS 겹침 상태에서 Esc 키와 ‹ › 절 이동
   - iOS push 화면의 상태
5. 기존 기능 회귀: 한국어 뜻 수정, 기기 번역, 차이 설명 칩 전환, 절을 옮길 때의 상태 초기화
6. 컴파일 오류 가능성: 격리, 존재하지 않는 API, 타입 추론
7. `Localizable.xcstrings`: 형식 지정자, 복수형 구조
