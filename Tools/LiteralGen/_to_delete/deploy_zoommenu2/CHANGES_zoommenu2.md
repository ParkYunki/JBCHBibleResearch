## 5. 검토 B1: 토글할 때 배치가 바뀌는 문제
- 원인: `ViewThatFits`가 지금 보이는 라벨("편집"/"뷰어")과 아이콘(펜/눈)만 잼 → ru 402pt 2↔3, en 440pt 1↔2.
- 수정(iOS 토글만, VerseZoomView.swift): `Label { ZStack { 보이는 글자; 다른 상태 글자.hidden().accessibilityHidden(true) } } icon: { ZStack { 보이는 아이콘; 다른 아이콘.hidden()… } }`.
  두 상태 중 넓은 쪽 폭을 늘 차지. 탭 영역은 버튼 스타일 그대로(폭만 넓은 쪽으로 고정), 접근성 라벨은 버튼의 `accessibilityLabel` 그대로. 아이콘만 후보(`.iconOnly`)에서도 아이콘 ZStack이 넓은 쪽 폭 유지.
- 한국어: "편집"·"뷰어" 글자 폭 같음(각 약 27.6pt). 펜 상태에서 눈 아이콘 폭(펜보다 약 5pt 넓음 추정)만큼 예약 → 402pt 추정 1번 386pt + 약 5 ≤ 402, 1번 유지. 위 표는 이미 두 라벨 중 넓은 쪽으로 계산했음.
- 맥 하단 버튼줄 토글은 `ViewThatFits`가 없어 손대지 않음.

## 절 번호 폭(시 119:176 등) — 보고만
- 같은 방식(숨긴 "176절" 겹치기)으로 막을 수 있으나, `VerseLayerStrip`이 서식 문자열을 몰라 호출부 2곳에서 최대 폭 견본(`String(localized: "\(176)절")`)을 따로 넘겨야 함.
- 비용: 한국어는 "176절"(약 52pt)이 최소 폭 58pt 안이라 영향 없음. 다른 언어는 1~2자리 절에서도 묶음이 넓어져(예: es "Versículo 4" → "Versículo 176" 폭, +약 17pt) 아이콘만 후보로 떨어지는 경우가 늘어남.
- 절 이동(‹ ›)은 토글보다 드물고 장 안에서 자릿수가 바뀌는 순간에만 생기므로 이번에는 넣지 않음. 원하면 견본 매개변수 + 숨긴 Text 겹치기로 수 줄이면 됨.
