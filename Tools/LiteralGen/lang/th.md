# Language card: th — ไทย
- Target Bible: THKJV (พระคัมภีร์ภาษาไทยฉบับ KJV)
- "Textus Receptus" term: Textus Receptus
- "critical text" term: ต้นฉบับเชิงวิพากษ์
- "close" sentence: Greek → `ใกล้เคียงต้นฉบับกรีก` / Hebrew → `ใกล้เคียงต้นฉบับฮีบรู`
- Style: เครื่องหมาย “ ” ใช้ ข้าพเจ้า/ท่าน แบบพระคัมภีร์ THKJV is CC BY-NC-ND: quote only short phrases.

Examples (Philemon 2, 12, 18, 25 — pilot output, TSV):
```
2	และถึงอัปเฟียพี่น้องหญิง และถึงอารคิปปัสเพื่อนทหารของเรา และถึงคริสตจักรที่อยู่ในบ้านของท่าน	“ผู้เป็นที่รัก” ตาม Textus Receptus (ἀγαπητῇ) ส่วนต้นฉบับเชิงวิพากษ์เขียนว่า “พี่น้องหญิง” (ἀδελφῇ)
12	ข้าพเจ้าส่งเขากลับไปหาท่าน คือตัวเขาเอง ซึ่งเป็นดวงใจของข้าพเจ้าเอง	“เหตุฉะนั้นท่านจงรับเขาไว้” ตาม Textus Receptus (σὺ δὲ … προσλαβοῦ) ซึ่งไม่มีในต้นฉบับเชิงวิพากษ์ “ดวงจิต” แปล σπλάγχνα
18	และถ้าเขาทำผิดต่อท่านในสิ่งใด หรือเป็นหนี้ท่าน จงคิดสิ่งนั้นเอาจากข้าพเจ้า	ใกล้เคียงต้นฉบับกรีก
25	ขอพระคุณขององค์พระเยซูคริสต์เจ้าดำรงอยู่กับจิตวิญญาณของท่านทั้งหลาย	“ของเรา” “เอเมน” และหมายเหตุท้ายจดหมาย (เขียนจากกรุงโรม ส่งโดยโอเนสิมัส) มาจาก Textus Receptus ไม่มีในต้นฉบับเชิงวิพากษ์
```
