# Language card: zh — 中文（简体）
- Target Bible: CUV1919S (官话和合译本 1919 上帝版，简体字版；底本为繁体 CUV1919)
- "Textus Receptus" term: 公认经文（Textus Receptus）／第二次起作「公认经文」
- "critical text" term: 校勘本文
- "close" sentence: Greek → `接近希腊文原文。` / Hebrew → `接近希伯来文原文。` / Aramaic → `接近亚兰文原文。`
- Style: 直译用现代白话简体中文。神名：上帝（θεός/אֱלֹהִים，与上帝版一致），耶和华（YHWH，与和合本一致），主（κύριος/אֲדֹנָי）。人名、地名用和合本写法。引号「」，内层『』。引用和合本原文时照录（文言、旧字形不改），只引短语。
