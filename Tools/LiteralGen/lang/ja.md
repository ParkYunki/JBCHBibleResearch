# Language card: ja — 日本語
- Target Bible: JPBUNGO (文語訳聖書)
- "Textus Receptus" term: 公認本文(テクストゥス・レセプトゥス)／2回目以降は「公認本文」
- "critical text" term: 校訂本文
- "close" sentence: Greek → `原文に近い。` / Hebrew → `原文に近い。`
- Style: 直訳は現代の口語・である調。かぎかっこ「」。訳文の引用は文語のまま。

Examples (Philemon 2, 12, 18, 25 — pilot output, TSV):
```
2	また姉妹アピヤへ、私たちの戦友アルキポへ、そしてあなたの家にある教会へ。	校訂本文どおり「姉妹」(ἀδελφῇ)。「我らと共に戰鬪をなせる」は συστρατιώτης(戦友)を説明的に訳したもの。
12	私は彼をあなたのもとに送り返した。彼を、すなわち私自身のはらわたを。	校訂本文どおり、公認本文(テクストゥス・レセプトゥス)の「彼を受け入れよ」(προσλαβοῦ)はない。σπλάγχνα を「心」と訳している。
18	もし彼があなたに何か損害を与えたか、負債があるなら、それを私の勘定にしなさい。	原文に近い。
25	主イエス・キリストの恵みが、あなたがたの霊とともに。	校訂本文どおり「我らの」と「アーメン」がない。
```
